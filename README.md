## What it does

Interview Prep Copilot builds role-specific structured interviews in minutes: competency-mapped questions, rubric scorecards, and interviewer briefs — so every candidate gets a fair, consistent, high-signal interview.

## Key features

- **Competency mapping** — questions tied to the role's actual success profile.
- **Rubric scorecards** — anchored 1–5 scales; no more vibe-based hiring.
- **Interviewer briefs** — candidate context + what to probe, per interviewer.
- **Debrief summaries** — scores aggregated with disagreement highlights.
- **Compliance-safe questions** — flags legally risky phrasing automatically.

## Who it's for

Hiring teams who want consistent, defensible interviews without weeks of process design.
